# Responsive website assistant — working description, name undecided

- What it is: a tool that helps people adapt a website designed for one screen size to other sizes, with live previews, visual layout controls, and instructions or code changes for an AI coding agent.
- Who it is for: people who have already built a mobile-screen or laptop-screen version of their website and need to quickly make it responsive on other screens. Specific profession, framework, purchase frequency, and acquisition channel remain undecided.
- What it sells, at what price: responsive adaptation and fine-tuning; price and commercial model undecided.
- Where and how: preferably usable inside Codex or VS Code with the existing project; a website with a preview and a right-hand property panel is the fallback. The exact integration and source-code connection are not yet decided.
- Budget and constraints: no budget, team, timeline, or technical stack supplied. User wants attractive, professional results that understand the original design and make coding easier.

## The two proposed workflows

1. User chooses screen/device previews and visually edits layout, placement, typography, sizes, and positioning. The product exports a file an AI agent uses to recreate those edits.
2. AI first adapts the existing single-screen design to other sizes; the user then fine-tunes those results in the same visual interface.

These are product ideas for assessment, not authorization to implement or launch a new application.

## Clarified primary job

The founder's main focus is reducing the annoying back-and-forth needed to correct responsive layouts in AI-built websites. AI sometimes produces the wrong appearance at other screen sizes, requiring the user to repeatedly return to the IDE or Codex and explain changes in prompts. The core value is a visual way to express the desired responsive result and give the agent precise implementation context. Automatic adaptation is an optional starting point; eliminating the correction loop is the primary product outcome.
