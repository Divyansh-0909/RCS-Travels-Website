# Board brief: responsive website assistant

Read ../idea.md for the idea record. This brief stands alone for reviewers.

## What the founder described

The founder experiences making AI-built websites responsive as annoying and wants to help people who already have a website that looks good at one screen size (mobile or laptop) quickly adapt it to other sizes.

They proposed two workflows:

1. Display the existing website in selectable device/screen previews. A right-hand property panel inspired by Graphical lets the user change layout, element placement and sizing, typography, and positioning at different sizes. Export a file that tells a coding agent how to implement the result.
2. AI analyzes the initial website and creates responsive adaptations first. Users then edit and fine-tune these adaptations in the same visual editor.

The founder specifically asks whether the AI can understand the original design well enough to produce good, professional adaptations, whether this business is worth building, and whether it would make coding easier.

## Clarifications provided by the founder

- Initial user: someone who has built the website for one device size and needs other sizes quickly; not restricted to a profession yet.
- Preferred delivery: inside Codex or VS Code. If that is not possible, a standalone website with preview and a property panel.
- Brand name and price: both undecided.
- No stack, team, budget, launch date, willingness-to-pay evidence, or measured time savings supplied.
- Conversion should work in either direction: mobile to larger screens and laptop to smaller screens.
